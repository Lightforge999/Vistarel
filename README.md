# Vistarel

**Vistarel** is a lightweight image viewer, comparison and batch-processing application for Windows.

> Freeware for Windows 10/11. Source code is not distributed.

## Features

- Fast image viewing with folder navigation, zoom, pan and fullscreen mode
- Image comparison tools
- Batch crop, rotate, resize, convert and rename
- Drag-and-drop workflow
- Graphite, Pearl and System themes
- Russian and English interface
- Open images in Photoshop or another installed application
- Portable and installer distributions

## Supported formats

Vistarel supports common image formats through its bundled runtime, including JPEG, PNG, WebP, TIFF, BMP, GIF, ICO and other supported image formats.

Some formats may be available for viewing only, while export support depends on the selected output format.

## Download

Use the **Releases** section of this repository to download Vistarel.

For each release, the intended downloads are:

- `Vistarel-<version>-Windows-x64-Setup.exe` — standard Windows installer
- `Vistarel-<version>-Windows-x64-Portable.zip` — portable version

## System requirements

- Windows 10 or Windows 11
- 64-bit Windows
